# Skills live here, not in a harness

Skills are canonical at [`_Agents/skills/`](../../skills/) and shared by every platform, so a capability
written once works everywhere. Never author a skill into a harness's private directory — see
[`README.md`](../../../README.md#set-up) and
[`watchtower` reference → Adding a skill](../../skills/watchtower/reference.md#adding-a-skill).
